# Yah Bamba - Portfolio

Portfolio professionnel pour Yah Bamba, Architecte de Solutions Digitales.

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Déploiement

Ce projet est configuré pour être déployé sur Vercel.

## Structure du projet

```
src/
├── app/                    # Next.js App Router
│   ├── globals.css         # Styles globaux
│   ├── layout.tsx          # Layout principal
│   └── page.tsx            # Page d'accueil
├── components/
│   ├── layout/             # Composants de layout
│   ├── portfolio/          # Composants du portfolio
│   └── ui/                 # Composants UI réutilisables
├── hooks/                  # React hooks personnalisés
├── i18n/                   # Internationalisation
└── lib/                    # Utilitaires
```

## Technologies

- Next.js 15
- TypeScript
- Tailwind CSS
- Framer Motion
- Radix UI
